# React + TypeScript + Vite

Steps to start the project

```nvm use v22```

```yarn && yarn dev```

## About the project

The project was created using Vite + React + Typescript technologies and 
also with tailwind library for better styles creation. 
In this project was created number list creation, storage this list to localstorage to keep the progress
and edit the number items. In this project I used my custom hooks for better and easier work with localStorage and debounce values.
In `/components/ui/` directory I placed UI components which was used for default components as button, typography and input.
